# Mini IT Support Ticketing System

## Project Overview

Designed and built an automated IT Service Desk workflow using Microsoft Forms, Power Automate, and Excel Online to simulate a real-world helpdesk environment.

The system allows users to submit support requests, automatically creates tickets, assigns priorities, routes issues to the correct teams, and tracks progress through resolution. The goal was to reduce manual work, improve response times, and prevent high-priority incidents from being missed.

This project demonstrates hands-on IT support skills, troubleshooting ability, workflow automation, and business-focused process improvement.

---

## Tools Used

- Microsoft Forms
- Power Automate
- Excel Online
- Microsoft 365
- SLA Tracking
- Incident Management
- Workflow Automation

---

## Key Features

- Automated ticket creation and logging
- Priority-based escalation workflow
- SLA tracking for response management
- Automatic routing across Service Desk, Network, and Security teams
- Live dashboard for ticket visibility and workload tracking
- Timestamp generation and ticket ID management

---

## Challenges Solved

During implementation, I resolved several real troubleshooting issues including:

- Response ID mapping failures in Power Automate
- Invalid Excel table structure preventing ticket logging
- Expression errors such as timestamp generation failures
- Flow trigger and save issues
- Escalation logic problems affecting priority routing

These fixes improved reliability and helped the workflow function like a real support environment.

---

## Business Value

This project improved operational efficiency by reducing manual ticket handling and ensuring faster response to urgent incidents.

It also improved visibility across support teams through live reporting and better ticket ownership, supporting stronger service delivery and business continuity.

Most importantly, it strengthened my understanding of project management, IT operations, and how support processes directly impact business performance.

---

## Outcome

Successfully built a working automated IT Support Ticketing System that reflects real Service Desk operations and demonstrates practical experience in troubleshooting, process improvement, and support automation.
